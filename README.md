# Max Inverse Index（MII）

**看看 Max 又买了啥。**

公开地址：`https://cortana-hk.github.io/max-inverse-index/`

一个由 GitHub Pages 托管的个人持仓观察站，展示累计/今日收益率、MII 指数、持仓权重、单持仓浮动盈亏与持仓变化。

## 数据与安全

- 本地 TIGER 项目的 `tools/mii_publisher.py` 只读采集 Tiger 账户，默认每 60 秒更新。
- `data/latest.json`、`data/history.json`、`data/events.json` 是唯一公开数据。
- 公开标的比例和收益率，但不公开股数、现金、成本金额、总资产、账户号或订单号。
- 券商配置和私密收益状态只保存在 TIGER 已忽略的本地目录，本仓库不包含交易源码或凭证。
- 网页直接读取 raw JSON，无第三方脚本、无追踪器、无浏览器密钥。数据提交不会触发 Pages 重新部署。

## 口径

首次有效快照的 MII 指数为 100，累计收益率为 0。收益按基金份额法计算；本地显式记录的出入金调整份额，不计为投资盈亏。今日收益使用香港时间上一自然日最后净值。持仓变化来自相邻快照，不冒充逐笔成交流水。

MII 是个人展示品牌，不是可交易金融产品。数据可能延迟，仅供记录，不构成投资建议。
