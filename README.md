# Max Inverse Index（MII）

**看看 Max 又买了啥。**

公开地址：`https://cortana-hk.github.io/max-inverse-index/`

MII 是与 Max 账户收益反向联动的个人指数。网页展示 MII 累计/今日收益、指数走势、订单时间与成交价格，以及当前持仓权重、平均成本、当前价格和浮动盈亏。

## 计算方法

账户区间收益率 `r = 当期单位净值 / 上期单位净值 - 1`，MII 按 `MII(t) = MII(t-1) × (1-r)` 逐区间计算。单位净值通过基金份额法剔除出入金影响。MII 累计和今日收益是相应区间的点位变化率，方向与账户相反。

后台保留最早可用快照以来的完整指数历史，订单事件从本地成交记录全量回填。页面基点默认为 100，可在网页上修改并保存在当前浏览器中；它只缩放点位显示，不影响收益率或后台历史。

## 数据与安全

- 本地 TIGER 项目的 `tools/mii_publisher.py` 只读采集账户，默认每 60 秒更新。
- `data/latest.json`、`data/history.json`、`data/events.json` 是唯一公开数据。
- 允许公开标的、仓位权重、平均成本、当前价格、订单时间和成交价格。
- 不公开持股数量、成交数量、资金金额、账户号或订单号。
- 券商配置和私密收益状态只保存在 TIGER 已忽略的本地目录，本仓库不包含交易源码或凭证。
- 网页直接读取 raw JSON，无第三方脚本、无追踪器、无浏览器密钥。数据提交不会触发 Pages 重新部署。

MII 是个人展示品牌，不是可交易金融产品。数据可能延迟，仅供记录，不构成投资建议。
